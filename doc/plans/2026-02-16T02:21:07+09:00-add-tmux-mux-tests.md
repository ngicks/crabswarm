# Add tests for tmux mux provider

## Context

The tmux mux provider (`pkg/mux/tmux/`) was implemented but has no tests. We need unit tests for pure parsing functions, unit tests for the executor, and integration tests for tmux session/window/pane operations. tmux is available at `/root/.nix-profile/bin/tmux`. Socket isolation (`-L` flag) enables parallel test runs.

## Files to create

1. **`pkg/mux/tmux/parse_test.go`** — Unit tests for parsing functions (no tmux needed)
2. **`pkg/mux/tmux/exec_test.go`** — Unit tests for executor construction and arg building
3. **`pkg/mux/tmux/tmux_test.go`** — Integration tests using real tmux with socket isolation

## Step 1: `parse_test.go` — Pure unit tests

Table-driven tests for all parse functions:

- **`TestParsePaneInfo`** — valid line (`"%0\t2"` → id=`%0`, idx=2), zero index, missing tab (error), invalid index (error), empty string (error), tab-only (error)
- **`TestParsePaneIDs`** — normal (`"%0\n%1\n%2"` → 3 IDs), single, empty → nil, trailing newline (`"%0\n%1\n"` → includes empty trailing element — documents current behavior)
- **`TestParseWindows`** — 3-window input (verify count + IDs), empty → nil, malformed line (only 2 fields) skipped
- **`TestParsePanes`** — 2-pane input (verify count + IDs), empty → nil, malformed line skipped

## Step 2: `exec_test.go` — Executor unit tests

- **`TestNewExecutor`** — default path: `newExecutor("", "")` → `tmuxPath == "tmux"`; custom path: `newExecutor("/usr/bin/tmux", "")` → `tmuxPath == "/usr/bin/tmux"`
- **`TestBuildArgs`** — no socket: `buildArgs(["list-panes"])` → `["list-panes"]`; with socket: `newExecutor("", "mysock").buildArgs(["list-panes"])` → `["-L", "mysock", "list-panes"]`

## Step 3: `tmux_test.go` — Integration tests

### Test helpers (file-local)

- `tmuxPath()` — resolves tmux binary via `exec.LookPath("tmux")`; **hard error** (not skip) if not found
- `testConfig(t, name) Config` — returns Config with unique `SocketName` derived from `strings.ReplaceAll(t.Name(), "/", "_")`
- `newTestSession(t) *Session` — creates session, registers `t.Cleanup` with `kill-server` on the test socket
- `pollCapture(t, p, match, timeout)` — polls `Capture` until output contains `match` or timeout, replacing `time.Sleep`

### Naming convention

All integration test functions are prefixed with `TestTmux` (e.g. `TestTmuxNew`, `TestTmuxSessionName`). This allows excluding them in environments without tmux:

```
go test ./pkg/mux/tmux/ -run '^TestTmux' -v   # run only tmux integration tests
go test ./pkg/mux/tmux/ -run '^(?!TestTmux)' -v  # skip tmux integration tests
```

This should be documented in the package's README.

### Test functions

| Test | What it verifies |
|---|---|
| `TestTmuxNew` | Creates session with valid ID (starts with `$`); duplicate → `ErrSessionExists` |
| `TestTmuxAttach` | Attaches to existing session (same ID); nonexistent → `ErrSessionNotFound` |
| `TestTmuxSessionName` | Returns correct session name |
| `TestTmuxSessionNewWindow` | Creates window with valid ID (starts with `@`) and correct name |
| `TestTmuxSessionList` | Lists windows (1 initial, then 3 after adding 2) |
| `TestTmuxSessionGetAt` | Valid index returns window; out-of-bounds/negative → `ErrWindowNotFound` |
| `TestTmuxSessionGetById` | Known ID returns window; unknown → `ErrWindowNotFound` |
| `TestTmuxSessionClose` | Kills session; subsequent Attach → `ErrSessionNotFound` |
| `TestTmuxWindowName` | Window name matches what was set at creation |
| `TestTmuxWindowSplit` | Table-driven with **fresh session per case**: split 0→1 pane (no-op), split 1→2, split 3→4, split 7→8 |
| `TestTmuxWindowList` | 1 pane initially; 3 after Split(2) |
| `TestTmuxWindowGetAtAndGetById` | Valid index/ID returns pane; out-of-bounds/unknown → `ErrPaneNotFound` |
| `TestTmuxWindowIndex` | Window indices match position in List |
| `TestTmuxWindowClose` | Window removed from session listing |
| `TestTmuxPaneName` | Pane has a non-empty name (title) |
| `TestTmuxPaneSendKeysAndCapture` | Send `"echo hello"` + `"Enter"`, poll Capture until "hello" found |
| `TestTmuxPaneSendKeysEmpty` | `SendKeys(ctx, nil)` and `SendKeys(ctx, []string{})` → no error |
| `TestTmuxPaneCaptureEdge` | `Capture(ctx, 0, 0)` → no error (may return empty) |
| `TestTmuxPaneIndex` | Pane indices match position in List after Split(2) |
| `TestTmuxPaneClose` | Pane removed from window listing after Close |

### Key design decisions

- **Socket isolation via `t.Name()`**: each test gets its own tmux server socket
- **`kill-server` in cleanup**: ensures full cleanup even with multiple sessions
- **Polling instead of `time.Sleep`**: `pollCapture` helper retries with 50ms intervals and a 3s timeout for SendKeys/Capture tests, avoiding flakiness
- **Fresh session per Split subtest**: each table case in `TestWindowSplit` uses `newTestSession` to avoid order-dependent pane counts
- **Split n=0 case**: verifies no-op behavior (pane count unchanged)
- **Table-driven for Split**: parameterized on split count to test multiple rounds of the algorithm
